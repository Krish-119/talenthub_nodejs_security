Location: src/services/authService.js | Severity: High

Description: Students were able to self-declare academic metrics, bypassing company cutoff criteria.

Correction: Force newly registered students to default initial values (CGPA 0.0, Backlogs 0), requiring coordinator verification before applying.

Case 2 – In-Memory Session and Rate-Limit Eviction Sweeper

Location: src/auth.js | Severity: Medium

Description: Memory leak caused by accumulating expired session tokens and rate-limiting IP keys.

Correction: Added a non-blocking background cleanup timer (setInterval(...).unref()) executing every 15 minutes.

Applied Correction Code:

// Periodic background memory sweeper
setInterval(() => {
  const now = Date.now();
  for (const [token, s] of sessions.entries()) {
    if (s.expires <= now) sessions.delete(token);
  }
  for (const [ip, a] of attempts.entries()) {
    if (a.reset <= now) attempts.delete(ip);
  }
}, 15 * 60 * 1000).unref();
